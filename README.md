##  Sobre o Projeto
O **Kaze Kitsune** é um estúdio de animação leve e potente, focado em desenvolvedores de jogos de plataforma e RPG. Ele permite que você saia do desenho estático e crie assets complexos que reagem ao ambiente do seu jogo através de iluminação dinâmica e profundidade.

###  Diferenciais para Jogos de Plataforma:
* **Efeitos Pop-out:** Transforme itens de cenário e personagens em objetos com profundidade real através de extrusão.
* **Normal Mapping:** Gere mapas de normais instantâneos para que seus personagens tenham sombras e luzes dinâmicas em motores como **Godot** e **Unity**.
* **Workflow de Animação:** Timeline integrada para gerenciar frames de movimento de forma intuitiva e rápida.

##  Funcionalidades de Design
* **ISO SHADE:** Sombreamento automático baseado em direção (Topo, Esquerda, Direita).
* **2.5D ISO Control:** Ajuste fino de *Tile Width* e *Height* para alinhamento perfeito de cenários isométricos.
* **Camadas Profissionais:** Gerencie diferentes partes do seu personagem ou cenário com total controle de visibilidade.
* **Estética Cyber-Dark:** Interface otimizada com as fontes *Cinzel Decorative* e *JetBrains Mono* para evitar o cansaço visual.

##  Como configurar no seu GitHub
Para que o design do seu repositório apareça corretamente:
1.  Mantenha o arquivo **`sprite.png`** na pasta raiz do repositório.
2.  Mantenha o arquivo **`sprite_studio.html`** na raiz (ou configure o GitHub Pages para a pasta correta).
3.  Verifique se o nome do arquivo da imagem é exatamente `sprite.png` (letras minúsculas).
