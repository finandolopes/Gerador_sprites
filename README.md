🦊 Kaze Kitsune - Studio de Animação
Kaze Kitsune é uma ferramenta web de edição de sprites e animação projetada para artistas técnicos e desenvolvedores de jogos que buscam um fluxo de trabalho ágil e integrado. Com uma interface inspirada em softwares profissionais de pixel art e animação, o estúdio permite a criação de recursos visuais prontos para motores de jogo modernos.

O que é e para que serve?
Este sistema serve como um ambiente completo para a manipulação de camadas, quadros (frames) e efeitos visuais em sprites. Seu diferencial reside na integração de recursos avançados como a geração de Normal Maps para iluminação dinâmica e ferramentas voltadas para o estilo 2.5D ISO.

Principais Funcionalidades:
Editor de Camadas e Timeline: Controle total sobre frames e camadas para animações complexas.

Modo 2.5D Iso: Ferramentas específicas para extrusão por offset e efeitos de "pop-out" em camadas.

Shading Automático (ISO SHADE): Sombreamento automático baseado em regiões (top/left/right) para objetos isométricos.

Normal Map Generator: Geração instantânea de mapas de normais para iluminação dinâmica em Godot e Unity.

Interface Futurista: Design escuro otimizado para longas sessões de trabalho, utilizando as fontes Cinzel Decorative e JetBrains Mono.

Tecnologias Utilizadas:
O projeto foi construído utilizando tecnologias web puras para garantir máxima compatibilidade e performance:

HTML5 & CSS3: Layout estruturado com CSS Grid e variáveis customizadas (Root) para temas dinâmicos.

JavaScript (Vanilla): Lógica de manipulação de canvas, renderização de grids e processamento de imagens.

Google Fonts: Tipografia especializada para uma estética "tech/studio".

Como Executar:

Clone o repositório:
Bash:
git clone https://github.com/seu-usuario/kaze-kitsune.git

Notas de Desenvolvimento
O projeto utiliza um sistema de grid dinâmico (#app) que organiza as barras de ferramentas, timeline e painéis de controle de forma responsiva para diferentes resoluções de tela.
