🦊 Kaze Kitsune — Animation Studio<p align="center"><img src="sprite.png" alt="Kaze Kitsune Preview" width="600"></p><p align="center"><strong>O estúdio de animação definitivo para desenvolvedores de jogos 2D e 2.5D.</strong></p><p align="center"><a href="https://finandolopes.github.io/Gerador_sprites/"><img src="https://img.shields.io/badge/ACESSO_DIRETO-CLIQUE_AQUI-00dcff?style=for-the-badge&logo=google-chrome&logoColor=white" alt="Link para o Projeto"></a></p>🕹️ Sobre o ProjetoO Kaze Kitsune não é apenas um editor de imagens; é um ecossistema focado em Game Design. Desenvolvido para suprir a lacuna entre o desenho estático e a implementação funcional em motores como Godot e Unity, o sistema permite que artistas criem assets complexos com profundidade isométrica e iluminação dinâmica em segundos.Ideal para criadores de jogos de plataforma, RPGs e projetos isométricos que buscam aquele "toque profissional" sem sair do navegador.🚀 Funcionalidades PrincipaisRecursoDescriçãoNormal Map GenGera mapas de normais automaticamente para iluminação real em tempo real.Extrusão 2.5DAplica profundidade e efeito pop-out em camadas 2D, criando um visual Pseudo-3D.ISO ShadeSombreamento automático inteligente para direções Top/Left/Right.Timeline StudioFluxo de trabalho baseado em frames para animações fluidas de personagens.Layers SystemGestão de camadas com modos de mesclagem e controle de opacidade.🎨 Design & EstéticaO ambiente foi projetado para minimizar a fadiga visual e maximizar a criatividade:Interface Dark Tech: Paleta baseada em tons de azul neon e dourado (--cy e --go).Tipografia: Uso da Cinzel Decorative para títulos épicos e JetBrains Mono para precisão técnica.UX Gamer: Comandos intuitivos e atalhos pensados na agilidade do desenvolvedor.🛠️ Stack TécnicaEngine Visual: HTML5 Canvas API (renderização de alta performance).Estrutura: CSS Grid & Flexbox (Layout responsivo e adaptável).Lógica: JavaScript Vanilla (Zero dependências externas, máxima velocidade).Assets: Fontes via Google Fonts para uma identidade visual única.📂 Como utilizar no seu fluxoDesenhe ou Importe: Comece seu sprite do zero ou carregue uma base.Anime: Use a linha do tempo para definir os estados de movimento.Adicione Profundidade: Utilize as ferramentas 2.5D para dar volume aos objetos.Exporte: Salve seus frames prontos para serem integrados ao seu motor de jogo preferido.<p align="center">Desenvolvido por <strong>Fernando Lopes</strong>.
